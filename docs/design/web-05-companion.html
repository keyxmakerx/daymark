SecurityFound by running it

What letting someone else's logic run on your phone actually costs.

Three findings, established by executing the code rather than reading the comment above it. The third is the one that shapes the design.

1. ne fails open on a signal that doesn't exist

Every other operator returns false for a missing signal. ne returns true, because undefined !== 1. A branch gated on a typo, or on a signal a later release renamed, shows instead of hiding.

Fix: unknown refs fail closed for every operator, and validate every ref against the closed vocabulary at authoring time so a typo is a useful error rather than a silent behaviour change.

2. The evaluator has no depth limit

50,000 nested all: [...] nodes throw Maximum call stack size exceeded. Bounded impact — it's the person's own device and the author is someone they granted — but a buggy generator hard-crashes the runner.

Fix: cap depth and node count at validation (16 and 256 are generous) and bound the recursion defensively at evaluation too.

3. Branches are an oracle — and this one is a design property, not a bug

Predicates evaluate on the device against private data, so a therapist never sees the result. But they can infer it from anything they can observe. Author "if hardDaysLast7 ≥ 3, offer a module they can accept", and the assignment lifecycle the therapist already watches — delivered, accepted, completed — leaks the branch condition. They learn a fact about private mood data that no grant gave them. Nothing was transmitted; the shape of the interaction did it.

It generalises: any authored branch whose arms differ in a therapist-observable way is an oracle for whatever it branched on.

Fix: partition the signal vocabulary by author — the table in the previous section. It falls straight out of the capability model that already exists.

What held up

No injection path. There is no {@html} anywhere in the tree; authored text renders through Svelte interpolation, which escapes by default. Structural, not a filter to bypass.

No code execution. The DSL is data — all / any / ref / op / value. No eval, no function references. And the honesty gate already rejects self-harm slots and requires non-diagnostic framing, so dialogue inherits all of it for free.
